## Arrhythmias & ECG

| Fact / discriminator | Must-remember answer |
|---|---|
| Infant SVT clue | Usually ≥220/min, abrupt fixed rhythm; normal sinus P absent/abnormal; perfusion overrides rate alone. |
| Child SVT clue | Usually ≥180/min, abrupt, fixed RR; consider fever-driven sinus tachycardia if variable. |
| AHA 2025 QRS | Narrow ≤0.09 s; wide >0.09 s in pediatric tachyarrhythmia algorithm. |
| AHA adenosine first | 0.1 mg/kg rapid IV/IO (max 6 mg) + rapid flush. |
| AHA adenosine second | 0.2 mg/kg rapid IV/IO (max 12 mg) + rapid flush. |
| IAP SVT 2022 | 100 → 200 → 300 microgram/kg stepwise; additional escalation is described by IAP and differs from two-dose AHA 2025. |
| SVT shock | Synchronized cardioversion 0.5–1 J/kg then 2 J/kg (AHA 2025). |
| VF/pVT first shock | 2–4 J/kg acceptable; 2 J/kg teaching first dose (AHA 2025). |
| VF/pVT later shock | 4 J/kg; escalate if needed, maximum 10 J/kg or adult maximum. |
| Brady CPR trigger | HR <60/min with poor perfusion despite effective oxygenation/ventilation. |
| Epinephrine arrest | 0.01 mg/kg IV/IO every 3–5 min per pediatric arrest pathway. |
| WPW sinus ECG | Short PR, delta wave, widened QRS; check ECG after SVT conversion. |
| Pre-excited AF | Irregular wide tachycardia: avoid AV nodal blockers; unstable → urgent electrical cardioversion. |
| EAT | Abnormal P axis; adenosine may reveal atrial activity without terminating tachycardia. |
| PJRT | Incessant long-RP SVT, negative inferior P, decremental retrograde accessory pathway. |
| JET | Postoperative automatic junctional tachycardia with possible AV dissociation; manage fever, catecholamines, electrolytes. |
| Complete AV block | P waves and QRS independent; persistent symptomatic cases may require pacing. |
| QTc Bazett | QT / √RR, both in seconds; assess age, rate and clinical context. |
| ECG paper | 25 mm/s: small square 0.04 s; large square 0.20 s; rate ≈300/large squares. |
| Long-QT vs CPVT | Long-QT may show prolonged resting QT; CPVT may have normal baseline ECG and exertional bidirectional VT. |

## Left-to-right shunts & obstructive lesions

| Fact / discriminator | Must-remember answer |
|---|---|
| ASD | Fixed split S2, LUSB flow murmur, right-heart volume overload. |
| VSD | Holosystolic LLSB murmur; large shunts cause left-heart volume overload after PVR falls. |
| Restrictive VSD | Small restrictive defect may have a louder murmur than a large nonrestrictive VSD. |
| PDA | Continuous left infraclavicular murmur, bounding pulses, wide pulse pressure. |
| AVSD | Common AV junction; Down syndrome association; superior/leftward QRS axis. |
| Coarctation | Arm–leg BP gradient, radiofemoral delay/weak femorals; neonatal shock as duct closes. |
| Turner | Coarctation and bicuspid aortic valve association. |
| Williams | 7q11.23 ELN deletion; supravalvar aortic stenosis. |
| Noonan | Pulmonary stenosis and hypertrophic cardiomyopathy. |
| Aortic stenosis | Systolic ejection murmur radiating to neck, LV pressure overload; exertional syncope is high-risk. |
| Pulmonary stenosis | LUSB systolic ejection murmur/click and RV pressure overload. |
| Eisenmenger | Advanced PVR with bidirectional/right-to-left shunting; closure can be unsafe. |
| CoA workup | Echo assesses arch anatomy; BP in upper and lower limbs helps screening. |
| PDA differential cyanosis | Advanced ductal right-to-left flow can desaturate legs more than right hand. |
| PGE1 | Supports ductal patency in duct-dependent systemic or pulmonary circulation; monitor apnea. |

## Cyanotic CHD & surgical physiology

| Fact / discriminator | Must-remember answer |
|---|---|
| TOF anatomy | VSD, overriding aorta, RVOT obstruction, RVH. |
| TOF severity | RVOT obstruction severity determines right-to-left shunt and cyanosis. |
| TOF spell | Calm, knee–chest, oxygen as indicated, expert escalation; avoid dehydration/agitation. |
| TOF CXR | Boot-shaped silhouette, concave pulmonary segment and oligemic lung fields. |
| TOF coronary | Coronary crossing RVOT may change repair approach. |
| d-TGA | Parallel systemic and pulmonary circuits; survival requires mixing. |
| d-TGA CXR | Classic egg-on-string; not universally present. |
| d-TGA BAS | Restrictive interatrial septum with inadequate mixing → urgent balloon atrial septostomy. |
| d-TGA surgery | Neonatal arterial switch with coronary transfer in suitable cases. |
| TAPVC | All pulmonary veins drain to systemic venous side; interatrial communication needed for systemic flow. |
| Obstructed TAPVC | Pulmonary edema/hypoxemia; urgent surgical repair after stabilization. |
| Supracardiac TAPVC | Snowman sign can appear later with unobstructed vertical venous drainage. |
| Truncus | Single arterial trunk + VSD; 22q11.2 deletion association. |
| HLHS | Duct-dependent systemic perfusion; Norwood establishes neoaorta and pulmonary flow source. |
| ccTGA | AV and VA discordance; systemic morphologic RV and spontaneous AV block risk. |
| Indian Glenn | Routine 6–12 months Class I; selected 4–6 months when appropriate (2019 consensus). |
| Indian Fontan | Often 4–7 years / 15–20 kg with favorable hemodynamics (2019 consensus). |
| Fontan physiology | Passive pulmonary flow requires low PVR, good ventricle and minimal AV valve regurgitation. |
| Hyperoxia test | Poor PaO2 rise suggests shunt physiology but cannot reliably distinguish cyanotic CHD from PPHN. |
| 22q11.2 | Conotruncal defects, thymic hypoplasia, hypocalcemia association. |

## Heart failure, myocarditis & PH

| Fact / discriminator | Must-remember answer |
|---|---|
| Infant HF | Sweating with feeds, tachypnea, hepatomegaly, poor growth. |
| Pulmonary overcirculation | Large VSD/PDA symptoms worsen after neonatal PVR declines. |
| Congestion | Loop diuretics relieve congestion; monitor kidney function/electrolytes. |
| Afterload | ACE inhibitors may help stable LV systolic dysfunction if perfusion/BP permit and no LVOT obstruction. |
| Myocarditis | Prodrome + troponin rise + LV dysfunction ± arrhythmia; shock can be fulminant. |
| Myocarditis CMR | Tissue characterization can support diagnosis in stable patients. |
| DCM | Dilated ventricle with reduced systolic function. |
| HCM | Myocardial hypertrophy, often asymmetric septum; dynamic obstruction can worsen with low preload. |
| RCM | Biatrial enlargement and impaired ventricular filling with relatively nondilated ventricles. |
| Tachycardiomyopathy | Sustained incessant tachycardia may produce reversible LV dysfunction. |
| PH echo | TR jet/RV size/septal flattening support PH assessment, not direct definitive PVR. |
| PH catheter | Expert right-heart catheterization measures pressure/PVR when indicated and safe. |
| PH crisis | Hypoxia, hypercarbia, acidosis increase PVR; oxygenation, ventilation, sedation and targeted rescue. |
| Fontan + PH | Elevated PVR impedes passive venous return and cardiac output. |
| Myocarditis shock | Urgent PICU/cardiac center support; cautious fluid strategy and advanced support readiness. |
